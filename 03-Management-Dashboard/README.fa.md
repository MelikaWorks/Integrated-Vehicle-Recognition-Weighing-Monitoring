# ۰۳ — پیشخوان مدیریت تحت وب

پیشخوان مدیریتی مبتنی بر ASP.NET Core MVC و .NET 8 برای مشاهدهٔ ثبت‌های پلاک و اطلاعات توزین. این بخش با پنل عملیاتی وب پلاک‌خوان متفاوت است: نقش فعلی آن خواندن و نمایش اطلاعات است؛ هدف توسعه، فراهم‌کردن یک پیشخوان مشترک برای پلاک‌خوان و توزین بود.

## وضعیت اجرا

طبق توضیح توسعه‌دهنده، به‌دلیل تهیه‌نشدن سرور اختصاصی، خود برنامه روی سیستم رئیس حراست اجرا و از مرورگر همان سیستم با localhost باز می‌شود؛ داده‌ها از SQL Server شبکه خوانده می‌شوند. محلی‌بودن میزبان وب به معنی محلی‌بودن دیتابیس نیست. عکس‌های مرورگر اجرای محلی را نشان می‌دهند؛ جزئیات محل استقرار از توضیح توسعه‌دهنده آمده است.

| بخش | محل اجرا یا منبع |
|---|---|
| مرورگر و میزبان پیشخوان | سیستم رئیس حراست؛ localhost |
| داده‌های پلاک و توزین | دیتابیس SQL Server در شبکه |
| تصاویر خودرو و پلاک | پوشهٔ تنظیم‌شده برای تصاویر؛ نیازمند دسترسی میزبان پیشخوان |

دسترسی به دیتابیس به‌تنهایی دسترسی به فایل تصاویر را تضمین نمی‌کند. کد نمایش تصویر، نام تصویر را از رکورد می‌خواند و فایل را از مسیر تنظیم‌شده می‌گیرد.

## مسیر توسعه و امکانات

۱. ساخت قالب اولیه با منوی چپ، سپس انتقال منو به راست برای رابط فارسی و اصلاح باز و بسته‌شدن آن.

۲. اتصال به دیتابیس و نمایش رکوردهای ثبت پلاک؛ در کد، سرویس خواندن اطلاعات توزین هم وجود دارد.

۳. افزودن ورود با نام کاربری و رمز، بررسی هش و نشست Cookie.

۴. افزودن نمودار تعداد ثبت‌های هفت روز اخیر، جست‌وجوی پلاک یا کد توزین، تازه‌سازی و لینک مشاهدهٔ تصویر خودرو و پلاک.

عکس‌ها جدول پلاک‌ها و نمودار را نشان می‌دهند؛ تصویر مستقلی از صفحهٔ توزین یا تصویر بازشدهٔ خودرو در این مجموعه نیست. تکمیل فرم‌های عملیاتی توزین یا اجرای OCR داخل خود پیشخوان ادعا نمی‌شود.

## احراز هویت و فناوری

- رمز ورود با `PasswordHasher<string>` از ASP.NET Core Identity هش و با `VerifyHashedPassword` بررسی می‌شود؛ برخلاف ابزار ساخت تنظیمات پایتون، این بخش واقعاً هش رمز دارد.
- کد دارای ساخت هش از مسیر `--hash-password`، ورود مبتنی بر Cookie و کنترل `[Authorize]` روی بخش‌های محافظت‌شده است. حساب ورود از تنظیمات خوانده می‌شود؛ سامانهٔ کامل مدیریت چند کاربر ادعا نمی‌شود.
- ASP.NET Core MVC، .NET 8، Razor، Dapper و Microsoft.Data.SqlClient؛ قالب AdminKit و CSS اختصاصی برای فارسی و منوی راست.
- پرس‌وجوهای بررسی‌شده برای پلاک، نمودار و توزین از نوع SELECT هستند؛ پیشخوان در این بخش نقش خواندن و نمایش دارد.

## کدهای منتخب

| پوشه | محتوا |
|---|---|
| `src/authentication/` | گزیدهٔ ساخت هش، بررسی رمز و تنظیم Cookie |
| `src/data-access/` | گزیدهٔ شمارش هفت‌روزه، جست‌وجوی پلاک و پرس‌وجوی توزین |
| `src/interface/` | قطعهٔ Razor منو و CSS منوی راست |

این قطعه‌ها از فایل‌های واقعی پروژه گرفته شده‌اند؛ کلاس‌ها، importها، راه‌اندازی و سایر منطق حذف شده‌اند و مجموعهٔ کامل قابل Build نیستند. [تنظیمات نمونه](config/appsettings.example.json) رمز و هش را با `********` و میزبان، کاربر و نام دیتابیس را با مقادیر نمونه نشان می‌دهد؛ ستاره‌ها هش معتبر برای ورود نیستند. رمز، هش واقعی، تنظیمات عملیاتی، EXE، DLL، پوشه‌های bin و obj و کتابخانه‌های آماده منتشر نشده‌اند.
