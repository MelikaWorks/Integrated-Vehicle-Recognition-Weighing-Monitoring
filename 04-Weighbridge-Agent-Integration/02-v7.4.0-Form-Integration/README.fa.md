# v7.4.0 — انتقال از پلاک‌خوان به فرم توزین

پایتون ایجنت محلی TowzinPlateAgent.exe را با اجزای پلاک و فایل پاسخ موقت مخصوص درخواست فراخوانی می‌کند. کد خروجی و متن دقیق پاسخ بررسی می‌شوند. timeout یا پاسخ ناقص باعث تکرار خودکار انتقال نمی‌شود. خروجی محلی ذخیره می‌شود، ولی این مسیر دیتابیس توزین را نمی‌خواند یا تغییر نمی‌دهد. ایجنت فقط فیلدهای پلاک را پر می‌کند؛ اپراتور ثبت وزن را انجام می‌دهد. راهنمای همراه می‌گوید اتصال CLI در زمان نگارش هنوز آزمون میدانی نشده بود. لاگ ارسالی بعداً یک تلاش v7.4.0 را نشان می‌دهد که به‌دلیل بازنبودن توزین در نشست کاربر ابزار شکست خورده؛ این مدرک موفقیت کامل مسیر نیست.

## کد منتخب و وضعیت شواهد

پوشهٔ `src` فقط قطعات واقعی منتخب را دارد؛ سایر منطق، راه‌اندازی و وابستگی‌ها حذف شده‌اند و این مجموعه مستقل قابل اجرا نیست. تست Windows، اجرای EXE و اتصال دیتابیس در بررسی فعلی انجام نشده است.

اسکرین‌شات واقعی سیستم توزین بعداً اضافه می‌شود؛ فعلاً عکس یا لینک تصویر ساختگی قرار نگرفته است. [گزیدهٔ لاگ جلسات](../evidence/agent-session.selected.log) برای تفکیک شروع برنامه از انتقال موفق در دسترس است.
