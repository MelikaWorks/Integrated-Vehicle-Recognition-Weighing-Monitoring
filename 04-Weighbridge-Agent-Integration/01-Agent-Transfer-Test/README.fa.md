# تست اولیهٔ انتقال ایجنت

ابزار تست، کنترل‌های native فرم WinForms را با چیدمان نسبی پیدا می‌کند، بخش‌های عددی را می‌نویسد و حرف را از فهرست واقعی توزین انتخاب می‌کند؛ مبتنی بر کلیک مختصات ثابت صفحه نیست. راهنمای تست، Windows Forms و .NET Framework 4.7.2 را هدف گرفته است. ابزار SQL ندارد و دکمهٔ پر، خالی یا چاپ را نمی‌زند. بازخوانی صحیح فیلدها به‌تنهایی دریافت همهٔ رویدادها توسط منطق توزین را ثابت نمی‌کند. راهنمای بعدی v7.4.0 موفقیت تست دکمه‌ای را گزارش کرده؛ راهنمای اولیه پیش از آن نوشته شده است. هنوز عکس این تست ارسال نشده است.

## کد منتخب و وضعیت شواهد

پوشهٔ `src` فقط قطعات واقعی منتخب را دارد؛ سایر منطق، راه‌اندازی و وابستگی‌ها حذف شده‌اند و این مجموعه مستقل قابل اجرا نیست. تست Windows، اجرای EXE و اتصال دیتابیس در بررسی فعلی انجام نشده است.

اسکرین‌شات واقعی سیستم توزین بعداً اضافه می‌شود؛ فعلاً عکس یا لینک تصویر ساختگی قرار نگرفته است. [گزیدهٔ لاگ جلسات](../evidence/agent-session.selected.log) برای تفکیک شروع برنامه از انتقال موفق در دسترس است.
